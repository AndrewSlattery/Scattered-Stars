# Appendix D: Historical Timeline

Some dates are approximate, historical records vary in reliability by source, and several entries are contested by the parties they concern—the Cartel's incorporation date most of all.

## The Scattering Era

| 2488 C | The Bangalore Breakthrough: Priya Vishwanathan's team sustains the first artificial warp bubble |
| 2502 C | The First Mandate Dynasty established                                     |
| 2511 C | First crewed warp vessel: two passengers, in a space smaller than a wardrobe |
| 2520 C | Reliable interstellar travel achieved; the Scattering begins in earnest    |
| 2534 C | Vishwanathan dies; her final papers pose the horizon problem, still unsolved |
| 2691 C | The archival vessel *Mnemosynë* commissioned by the Terran Heritage Foundation |

## The Cascade and after

| 2756 C | The Cascade. The Vandemeyer Declaration is read at Covenant Station and 847 worlds declare independence within a single standard year. The First Mandate Dynasty falls and the Long Interregnum begins |
| 2761 C | The Korsen Conference adopts the Charter of Freeholds, after rejecting fourteen proposed constitutions |
| ~2800 C| The orphaned *Mnemosynë*, renamed Haven Ascendant, locks its preservation-and-entertainment engine into place |
| 2847 C | The modern Mandate established; the Long Interregnum ends                  |
| 2891 C | Covenant Station destroyed in a piracy incident                            |
| 2893 C | Outer system mining colonies collapse; the Endeavour Fleet departs         |

## The building centuries

| 2901 C | Arrhenos planetfall at Campottonì; first generation born there 2919 C      |
| 2934 C | Mira Korsen founds the station that becomes Korsen's Anchorage; Ascendant opens the Paulista District |
| 2987 C | Wayline Logistics founded                                                  |
| 3089 C | The loose Terraforming Collective founded                                  |
| 3203 C | Traditional and unverifiable incorporation date claimed for the Sable Cartel |
| 3261 C | The Elysian Charter adopted; the Collective becomes the guild it remains   |
| 3278 C | Neo-Solar Republic constitution                                            |
| 3324 C | Gamma orbital complex construction begins above Verenstad                  |
| 3341 C | Nexus Financial Group founded; Cartel acquisition estimated around 3500 C  |
| 3401 C | Veritas Station founded by a consortium of mercenary companies             |
| 3412 C | Houses Valdorian and Meridian ennobled in the same year                    |
| 3423 C | The Arrhenos–Freeholds framework signed                                    |
| 3486–87 C | Arrhenos Second Republic ends; the Third Republic established           |
| 3512 C | Callum Vance's strike on Hephaestus; the Roughneck boom begins             |
| 3524 C | Arrhenos abolishes the childhood placement; sorting moves to the adult guild boards |

| 3567 C | The Grey Incursion. The Mandate occupies three Freehold systems and withdraws after four years. The Void Reapers founded in the same year |
| 3612 C | Aegis Security Solutions founded                                           |
| 3644 C | The Empty Quarter Event                                                    |
| 3672–89 C | The Roughneck Labour Wars, ended by compromise                          |
| 3702 C | The Vega consolidation; House Valdorian reaches archducal rank             |
| 3712 C | The Pirate Fleets broken by coordinated Freehold action                    |
| 3741 C | The Long Descent opens in Verenstad's Transient Quarter                    |
| 3782 C | The Collective begins the Veldtgrave restoration                           |
| 3795 C | Lysandra IV takes the Commercial Throne                                    |
| 3821 C | 17 Xuanzong takes the Stellar Throne                                       |

## Living memory

| 3829 C | The Sefkir Compact. A dozen Freeholds expel every identifiable Cartel subsidiary in a single coordinated season |
| 3831 C | Caelum Valdorian becomes Duke; the Marchetti's Folly restoration begins    |
| 3834–39 C | The Andromedan Banking War: a Vegan financial quarrel, fed (Arrhenos maintains) by Cartel money, burns for five years and ends in Arrhene arbitration |
| 3840 C | House Kraeven attainted, the first archducal attainder in two centuries. The NSR Census extends personhood to digital citizens |
| 3845 C | The Cassini Incident: Freehold salvage claims fought to exhaustion         |
| 3847 C | Teshen Briar elected Captain-Archivist of Haven Ascendant; Isadora Cassiline inherits her struggling house |
| 3850 C | The NSR Census extends personhood to forked individuals; the Brighthollow restoration begins |
| 3851 C | Cassius Dray elected Harbourmaster of Korsen's Anchorage; Edda Voss of the Sefkir Reach dies |
| 3854 C | The Bureau's Cartel assessment leaks: "We cannot confirm that the Directors are human, alive, or singular entities" |
| 3858 C | A Bureau registration sweep ignites the Yansieve Rebellion. Kellen Marsh's aurite strike begins the Three Falls rush. Mandate forces deploy to Kepler-442 |
| 3860 C | The NSR Census extends personhood to collective intelligences; Three Falls declares itself a Freehold |
| 3861 C | Republic physicists publish the fez-free gate-efficiency proof of concept  |
| 3862 C | Present day                                                                |

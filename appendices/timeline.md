# Appendix D: Historical Timeline

## The Scattering Era

| Year | Event |
|------|-------|
| 2488 C | **Bangalore Breakthrough** — Priya Vishwanathan's team sustains the first artificial warp bubble; the AV drive becomes possible |
| 2502 C | **First Mandate Dynasty** established |
| 2511 C | First crewed warp vessel (two passengers, a space smaller than a wardrobe) |
| 2520 C | Reliable interstellar travel achieved; the Scattering begins in earnest |
| 2534 C | Vishwanathan dies; her final papers pose the "horizon problem," still unsolved |
| 2691 C | The archival vessel *Mnemosynë* commissioned by the Terran Heritage Foundation |

## The Cascade and After

| Year | Event |
|------|-------|
| 2756 C | **The Cascade** — the Vandemeyer Declaration is read at Covenant Station; 847 worlds declare independence within a single standard year. The First Mandate Dynasty falls; the Long Interregnum begins. Last serious attempt at human political unification fails |
| 2761 C | **Korsen Conference** — the Charter of Freeholds adopted, after fourteen proposed constitutions are rejected |
| ~2800 C | The orphaned *Mnemosynë*, renamed **Haven Ascendant**, locks its preservation-and-entertainment engine into place |
| 2847 C | **Modern Mandate** established; the Long Interregnum ends |
| 2891 C | Covenant Station destroyed in a piracy incident; its survivors' memorial becomes Ascendant's Hanging Market |
| 2893 C | Outer system mining colony collapse; the **Endeavour Fleet** departs |

## The Building Centuries

| Year | Event |
|------|-------|
| 2901 C | **Arrhenos planetfall** at Campottonì |
| 2919 C | First generation born on Arrhenos (Foundation Day origin) |
| 2934 C | Mira Korsen founds the station that becomes **Korsen's Anchorage**; Ascendant opens the Paulista District, the first environmental reconstruction |
| 2947 C | Arrhenos First Republic established |
| 2956 C | Nemora wilderness treaty signed |
| 2987 C | Zespol (Research Complex Seven) established; Wayline Logistics founded |
| 3089 C | The loose **Terraforming Collective** founded |
| 3156 C | Arrhenos First Republic collapses; the Interregnum begins |
| 3203 C | Arrhenos Second Republic established. Traditional—and unverifiable—incorporation date claimed for the **Sable Cartel**, which has never confirmed a founding and may not have had one |
| 3261 C | The **Elysian Charter** adopted; the Collective becomes the guild it remains—the founding the guild actually dates itself from |
| 3278 C | **Neo-Solar Republic** constitution |
| 3324 C | Gamma orbital complex construction begins above Verenstad |
| 3341 C | Nexus Financial Group founded (Cartel acquisition estimated ~3500 C) |
| 3401 C | **Veritas Station** founded by a consortium of mercenary companies |
| 3412 C | Houses **Valdorian** and **Meridian** ennobled in the same year |
| 3423 C | The Arrhenos–Freeholds framework signed—in hindsight, the template for the capture |
| 3486–87 C | Arrhenos Second Republic ends; **Third Republic** established (current) |
| 3512 C | Callum Vance's strike on Hephaestus; the **Roughneck** boom begins, and never busts |

## The Long Modern Era

| Year | Event |
|------|-------|
| 3567 C | **The Grey Incursion** — the Mandate occupies three Freehold systems, discovers there is no one to make the rest surrender, and withdraws after four years. The Void Reapers mercenary company founded in the same year |
| 3612 C | Aegis Security Solutions founded |
| 3644 C | **The Empty Quarter Event** (see [Appendix E: Open Questions](mysteries.md)) |
| 3672–89 C | The Roughneck **Labour Wars**; ended by compromise, not victory |
| 3702 C | The Vega consolidation; House Valdorian reaches archducal rank |
| 3712 C | The Pirate Fleets broken by coordinated Freehold action |
| 3741 C | The Long Descent bar opens in Verenstad's Transient Quarter |
| 3782 C | The Collective begins the **Veldtgrave** restoration—the Lazarus Project's showpiece |
| 3795 C | **Lysandra IV** takes the Commercial Throne |
| 3821 C | **Xuanzong XVII** takes the Stellar Throne |

## Living Memory

| Year | Event |
|------|-------|
| 3829 C | **The Sefkir Compact** — a dozen Freeholds expel every identifiable Cartel subsidiary in a single coordinated season, and never let them back |
| 3831 C | Caelum Valdorian becomes Duke; the Marchetti's Folly restoration begins |
| 3834–39 C | **The Andromedan Banking War** — a Vegan financial quarrel, fed (Arrhenos maintains) by Cartel money, burns for five years; ends in Arrhene arbitration |
| 3840 C | **House Kraeven attainted**—the first archducal attainder in two centuries. The NSR's Centennial Census extends personhood to digital citizens |
| 3845 C | The Cassini Incident—Freehold salvage claims fought to exhaustion, settled by nothing |
| 3847 C | Teshen Briar elected Captain-Archivist of Haven Ascendant; Isadora Cassiline inherits her struggling house |
| 3850 C | NSR Census extends personhood to forked individuals; the Brighthollow restoration begins |
| 3851 C | Cassius Dray elected Harbourmaster of Korsen's Anchorage; Edda Voss of the Sefkir Reach dies, poor and at home |
| 3854 C | The Bureau of Internal Harmony's Cartel assessment leaks: *"We cannot confirm that the Directors are human, alive, or singular entities"* |
| 3858 C | A Bureau registration sweep ignites the **Yansieve Rebellion**; twelve-plus systems in revolt. Kellen Marsh's aurite strike begins the **Three Falls** rush |
| 3860 C | NSR Census extends personhood to collective intelligences; Three Falls declares itself a Freehold |
| 3861 C | Republic physicists publish the fez-free gate-efficiency proof-of-concept; every fez trader in human space takes note |
| 3862 C | **Present day** |

## Notes

Some dates are approximate. Historical records vary in reliability by source, and several of the entries above are contested by the parties they concern—the Cartel's incorporation date most of all.

# Faster-Than-Light Travel

Alcubierre-Vishwanathan (AV) drives enable interstellar travel by manipulating spacetime geometry. They only function in sufficiently flat spacetime, so that a "jump shell" surrounds each star system. This shell has a radius proportional to the cube root of the mass of the star. The jump shell of the solar system has a radius of approximately 30 AU.

Thus, a typical interstellar journey proceeds in three phases:
- sublight trek outwards to the jump shell of the home system (days to weeks)
- interstellar transit using the AV drive (hours)
- sublight trek inwards from the jump shell of the destination system (days to weeks)
